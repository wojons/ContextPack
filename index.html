ContextPack

What is ContextPack?

ContextPack is a client-side web tool that helps you quickly convert the contents of a ZIP archive or a folder into a single, formatted text block. This is ideal for preparing codebases or document sets for use as context in Large Language Model (LLM) prompts.

Why use ContextPack?

Manually extracting and concatenating file contents for LLMs is tedious and error-prone. ContextPack automates this process, ensuring a consistent, LLM-friendly format. It handles both text and binary files (with optional Base64 encoding for binaries), and works entirely in your browser—no data ever leaves your device.

How to use ContextPack

  1. Select either a ZIP file or a folder using the inputs below.
  2. Optionally, check "Include non-text files" to Base64-encode and include binary files.
  3. Wait for processing (progress is shown).
  4. Copy or download the output for use in your LLM prompt.
